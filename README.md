# Python Job Tracker

Aplicação de linha de comando desenvolvida em Python para gerenciamento e acompanhamento de candidaturas a vagas de emprego.

## Funcionalidades

* Cadastro de candidaturas
* Listagem de candidaturas
* Busca por empresa ou cargo
* Atualização do status da candidatura
* Exclusão de candidaturas
* Estatísticas do processo de candidatura
* Persistência de dados utilizando JSON

## Tecnologias

* Python 3
* JSON
* Git
* GitHub

## Execução

Clone o repositório:

```bash
git clone https://github.com/Kauan-Santos-Souza-Dev/python-job-tracker.git
```

Entre na pasta:

```bash
cd python-job-tracker
```

Execute:

```bash
python main.py
```

No Windows, também pode ser utilizado:

```bash
py main.py
```
